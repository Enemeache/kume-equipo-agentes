# Menú de secciones posibles

> **No es un formato.** Cada propuesta elige solo las secciones que ese cliente necesita, en el orden que mejor cuente su historia, y puede crear secciones nuevas.

| Sección | Cuándo suma |
|---|---|
| Portada (cliente, fecha, validez) | Siempre |
| Resumen / lo que vemos | Casi siempre: 3 frases que el dueño entienda sin leer el resto |
| Dónde están hoy (fortalezas + lo que falta) | Cuando el análisis encontró cosas concretas |
| Comparación con competidores | Cuando la competencia explica el problema o la oportunidad |
| Lo que nos contaron (respuestas clave) | Cuando el cliente necesita sentirse escuchado |
| El problema real | Cuando no es el que el cliente cree |
| La solución / estrategia (con nombre propio) | Siempre |
| Mockup o demo a medida | Web, feed, app, bot: cuando verlo vende más que explicarlo |
| Fases y cronograma | Proyectos de más de 2 semanas |
| Alcance: incluido / no incluido / qué necesitamos de ustedes | Siempre que haya riesgo de malentendidos |
| Inversión (una o varias opciones) | Siempre |
| Qué esperar (estimaciones explicadas) | Solo si hay base para estimar |
| Quiénes somos | Leads que no nos conocen |
| Próximos pasos + contacto | Siempre |
